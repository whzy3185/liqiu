# A3 Discovery Metadata Extension v3

After the complete, strain-disjoint MicroMass Discovery extension, the catalog
is extended by one independently donated source dataset: UCI Internet
Advertisements.  It is a CC-BY-4.0 binary classification task with 3,279 rows
and 1,558 documented features (three continuous and the rest binary), including
unknown continuous fields.

This candidate is admitted only to the pre-MIA pipeline: official archive,
reproducible numeric parser, frozen missing-value representation, structural
profile, GB structure probe, and hard filter.  No attack or membership result
may influence this sequence.  If it passes, it will use the already validated
independent reference/shadow/target A3 protocol; no group identifier is
documented in the official dataset metadata.
